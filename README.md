# ☕ Java Core Mastery & Algorithms

> 📚 **Laboratório de Estudos Avançados** baseados na "Maratona Java" (DevDojo).

Este repositório não contém apenas exercícios básicos. Ele serve como minha **Base de Conhecimento Central** sobre a linguagem Java (Standard Edition). Aqui exploro desde os fundamentos até tópicos avançados de engenharia de software, focando em performance e boas práticas.

## 🎯 Objetivos de Aprendizagem

O foco deste repositório é dominar a base para construir aplicações robustas com Spring no futuro.

### 🧠 Tópicos Explorados (Highlights)

| Módulo | Conceitos Chave Dominados |
| :--- | :--- |
| **Programação Orientada a Objetos** | Polimorfismo, Classes Abstratas, Interfaces, Coesão e Acoplamento. |
| **Collections API** | Lists, Sets, Maps, HashCode & Equals, Otimização de busca. |
| **Java Moderno (8+)** | **Lambdas, Streams API**, Method References, Optional. |
| **Tratamento de Erros** | Try-with-resources, Custom Exceptions, Stack Trace analysis. |
| **Tópicos Avançados** | Generics, Serialização, **Threads & Concorrência**, JDBC. |
